O que este teste verifica

✓ Página abre no Android
✓ Permissão de microfone, se o navegador oferecer reconhecimento de fala
✓ Reprodução de voz em português
✓ Interface inicial com avatar

Importante: esta página não usa IA, não envia sua fala para uma API própria e não controla dispositivos. O reconhecimento de fala do navegador pode usar um serviço de reconhecimento do próprio navegador/sistema.

Para melhores resultados, abra no Google Chrome e permita o microfone quando solicitado. Se o reconhecimento não estiver disponível ao abrir o arquivo local, o teste de voz falada ainda pode funcionar. Depois podemos hospedar a página com HTTPS e adicionar um backend seguro.
